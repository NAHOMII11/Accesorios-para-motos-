Durante el desarrollo del Sprint 1 implementé la capa de seguridad basada en JWT dentro de una arquitectura de microservicios con Spring Boot. Se configuró un auth-service encargado de generar tokens firmados mediante autenticación de usuario, y un api-gateway responsable de validar dichos tokens antes de permitir el acceso a rutas protegidas como /orders/**. Además, se crearon microservicios básicos (catalog-service y orders-service) con endpoints de prueba para verificar el correcto enrutamiento y control de acceso. Se realizaron pruebas con Postman para comprobar respuestas 401 sin token y 200 con token válido, asegurando que la seguridad funciona de manera adecuada dentro del flujo distribuido.
